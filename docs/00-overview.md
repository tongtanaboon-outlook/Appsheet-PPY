## วงจรการทำงานของแอป

```
① รับงานประจำวัน
   พนักงานได้รับงานจากลูกค้า → ระบบบันทึกลง "ตารางงานประจำวัน"
   (หนึ่งแถว = หนึ่งใบวางบิล: ชื่องาน, ทะเบียนรถ, จุดส่ง, ราคา, ScanStatus)

② สแกนหน้างาน
   พนักงานสแกนใบวางบิลที่ปลายทาง → "SCGนครหลวงJWDภูมิภาค"
   ระบบคำนวณอัตโนมัติ: ระยะทางที่เคลื่อนที่, เวลาใช้งาน, ความเร็ว
   และให้คะแนน PASS / WARNING / FAIL + รายการความผิดปกติที่พบ

③ ปริ๊นใบวางบิล
   บอท 14 เวอร์ชัน (ตามคลัง/สาขา: มโนยนต์, กระสอบ2, ไอโรบอท, เอเทน, MeSpace,
   บุญถาวรเกษตร, LINEMAN, Thai paper, เบทาโกร, สตีเบล, …)
   → "ข้อมูลการวางบิล" + "ปริ๊นใบวางบิล"

④ คิดราคา
   ราคาตามระยะทาง + ราคาจุดเพิ่ม + เรทน้ำมันดีเซล + ราคาคงที่/ที่แทนที่ (PriceOverride)
   → "ราคาในระบบก่อนส่งสินค้า"

⑤ เบิกส่วนต่าง
   เทียบราคาในระบบกับราคาจริงหลังส่ง → บอท "ทำเบิกส่วนต่างScgวังน้อย"
   → "ทำเบิกส่วนต่างScgวังน้อย" (136 คอลัมน์)

⑥ อนุมัติ
   ผู้ดูแลกดปุ่ม "อนุมัติ" → SET_COLUMN_VALUE ที่ "สถานะการอนุมัติ"
   (เงื่อนไข: ต้องเป็น ADMIN และยังไม่ได้อนุมัติ)

⑦ รับสินค้าคืน
   บอท "รับสินค้าคืน" → "รับงานคืนได้เงิน200" (สถานะ 6 แบบ: เพิ่ม 200 / เพิ่ม 50% ฯลฯ)

⑧ สรุปและรายงาน
   "สรุป_Shipment" / "สรุป_เจ้าของสินค้า" (ใช้ FILTER) → หน้าหลัก → export xlsx/csv

⑨ แจ้งปัญหาระหว่างวัน
   พนักงานแจ้งปัญหา 11 ประเภท → บอท Telegram → "แจ้งปั ญหาระหว่างวัน"
```

รายละเอียดและหลักฐานของแต่ละขั้น: [04-bots-and-automations.md](04-bots-and-automations.md)

## โมเดลความปลอดภัย

| ระดับ | กลไก |
|---|---|
| ระดับแถว (Row Security) | `=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())` — พนักงานเห็นเฉพาะแถวของตัวเอง ผู้ดูแล (ADMIN) เห็นทั้งหมด |
| ระดับคอลัมน์ | `Editable_If = =USERROLE()="ADMIN"` บนคอลัมน์ราคา/พิกัด → พนักงานแก้ไขไม่ได้ |
| ระดับการมองเห็น | `Show_If` เช่น `=ISNOTBLANK([InvoiceNo])` → ซ่อนข้อมูลที่ยังไม่พร้อม |
| ระดับการบังคับ | `Required_If` + `Error_Message_If_Invalid` เช่น "Invoice นี้ไม่ถูกต้อง, ไม่ใช่งานวันที่เลือก หรือสแกนรับไปแล้ว" |

ตารางที่มี security filter: `SCGนครหลวงJWDภูมิภาค`, `ข้อมูลการวางบิล`, `ข้อมูลการเข้าบำรุงรักษา`,
`ตารางงานประจำวัน`, `แจ้งปั ญหาระหว่างวัน`, `รับงานคืนได้เงิน200`, `ทำเบิกส่วนต่างScgวังน้อย`
(ดูคอลัมน์ `security_filter` ใน `app/tables.csv`)

## ข้อจำกัดของชุดข้อมูลนี้

1. **ไม่มีข้อมูลระดับแถว** — มีแต่โครงสร้าง ตัวเลขทางธุรกิจยังคำนวณไม่ได้
2. **ไม่มีนิยามบอท** — AppSheet Application Documentation ไม่มีส่วน Automation/Bot
3. **ตารางบอทเป็น state machine** — ห้ามนับแถวจากตารางบอท
4. **มี PII** — ชื่อ-นามสกุล, เบอร์โทร, ทะเบียนรถ, GPS, ที่อยู่, ข้อมูลลูกค้า
5. **สูตรมาจากการคัดลอกจาก PDF** — บางจุดอาจมีช่องว่าง/อักขระเพี้ยนจากต้นฉบับ
   ถ้าจะใช้สูตรจริงให้ยืนยันใน AppSheet อีกครั้ง
6. **ยังไม่มีข้อมูลจาก Google Sheet** — ต้อง export ตาม `data/README.md`
