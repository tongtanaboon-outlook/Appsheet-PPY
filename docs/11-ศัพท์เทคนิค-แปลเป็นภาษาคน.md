# 📘 ศัพท์เทคนิค แปลเป็นภาษาคน

> พจนานุกรมคำที่เจอในรีโปนี้ (ทั้งคำของ AppSheet และคำของการทำงานกับข้อมูล)
> อ่านเฉพาะตัวที่เจอเมื่อคุณเปิดไฟล์ ถ้าไม่เจอคำที่ต้องการ ถามผมได้เลย

---

## กลุ่มที่ 1 — คำเกี่ยวกับ "ข้อมูล"

| คำ | แปลว่าง่าย ๆ | ตัวอย่างในแอปคุณ |
|---|---|---|
| **ตาราง (Table)** | ตารางข้อมูล มีแถว (ข้อมูล) และคอลัมน์ (หัวข้อ) | `ตารางงานประจำวัน` |
| **คอลัมน์ (Column)** | ช่องข้อมูล 1 ช่อง เช่น "ชื่อลูกค้า" | `รหัสลูกค้า` |
| **แถว (Row)** | ข้อมูล 1 ชุดของตารางนั้น เช่น งาน 1 ใบวางบิล | แถวที่ 1, 2, 3 … |
| **คีย์ (Key)** | ช่องที่เป็น "รหัสประจำ" ของแถวนั้น ใช้ค้นได้ | `ID_งานประจำวัน` |
| **Part of key** | กลุ่มของคอลัมน์ที่ใช้ร่วมกันเป็นรหัส (มีได้หลายคอลัมน์รวมกัน) | — |
| **Schema** | "แบบฟอร์ม" ที่บอกว่าตารางนี้มีอะไรบ้าง ใช้ตรวจว่าข้อมูลครบ | ไฟล์ `app/tables.csv` |
| **ชนิดข้อมูล (Type)** | ชนิดของค่าที่เก็บได้ เช่น ข้อความ / ตัวเลข / วันที่ / พิกัด | `LatLong` = พิกัดแผนที่ |
| **Ref / คอลัมน์อ้างอิง** | ช่องที่เก็บ "รหัสของแถวในตารางอื่น" แล้วแอปไปดึงข้อมูลมาแสดงให้ | `SM_Link_SCG` |
| **Referenced key column** | ช่องในตารางปลายทางที่ถูกอ้างอิง | `ID_งานประจำวัน` |
| **Enum / ตัวเลือก** | ช่องที่ให้เลือกจากรายการที่กำหนดไว้ | `ScanStatus` = รอสแกน / คลังตัดสินค้า / สแกนรับแล้ว |
| **EnumList** | เลือกได้หลายค่า | `Invoice No` |
| **Virtual column** | ช่องที่ไม่ได้เก็บในฐานข้อมูล แต่คำนวณสด ๆ | `ระยะขยับจากจุดเริ่มต้น_เมตร` |
| **PII (ข้อมูลส่วนบุคคล)** | ข้อมูลที่ระบุตัวคนได้ ต้องระวังเวลาส่งออก | ชื่อ-นามสกุล, เบอร์โทร, ทะเบียนรถ, GPS |

## กลุ่มที่ 2 — คำเกี่ยวกับ "สูตรและกฎ"

| คำ | แปลว่าง่าย ๆ |
|---|---|
| **App formula** | สูตรที่คำนวณใหม่ทุกครั้งที่ข้อมูลเปลี่ยน |
| **Initial value** | ค่าเริ่มต้นที่ใส่ให้ตอนสร้างแถวใหม่ (คำนวณ 1 ครั้งตอนสร้าง) |
| **Valid_If** | กฎ "ค่านี้ต้องโอเค ถึงจะบันทึกได้" (ถ้าผิด → ขึ้นข้อความบอก) |
| **Error_Message_If_Invalid** | ข้อความที่ขึ้นเมื่อ Valid_If ไม่ผ่าน |
| **Required_If** | กฎ "ช่องนี้ต้องกรอก ถึงจะบันทึกได้" (ต่างจาก Valid_If ตรงที่ไม่บอกว่าอะไรผิด แต่บอกว่า "ยังไม่ครบ") |
| **Editable_If** | กฎ "ใครแก้ไขได้" |
| **Show_If** | กฎ "แสดงช่องนี้ต่อเมื่อ..." |
| **Reset on edit?** | "แก้ช่องนี้แล้วให้ล้างค่าอีกช่องไหม" |
| **Suggested values** | รายการตัวเลือกที่แนะนำให้เลือก |
| **Security filter** | กฎซ่อนแถวจากคนที่ไม่มีสิทธิ์ (ระดับแถว) |
| **Column Order List** | ลำดับช่องที่แสดงในหน้าจอ |
| **Locale / LocaleName** | รูปแบบวันที่/ตัวเลขของประเทศ (`en-GB` = อังกฤษ ยุโรป) |
| **NFC Scannable** | อ่านด้วย NFC (แตะชิป/บัตร) ได้ไหม |

### ฟังก์ชันที่เจอในแอปคุณ

| ฟังก์ชัน | แปลว่า |
|---|---|
| `TODAY()` | วันนี้ |
| `NOW()` | เวลาตอนนี้ (วัน+เวลา) |
| `TIMENOW()` | เวลาตอนนี้ (เฉพาะเวลา) |
| `UNIQUEID()` | สร้างรหัสสุ่มไม่ซ้ำ |
| `USEREMAIL()` | อีเมลคนที่ล็อกอินอยู่ |
| `USERNAME()` | ชื่อคนที่ล็อกอินอยู่ |
| `USERROLE()` | บทบาทของคนที่ล็อกอิน (`ADMIN` = ผู้ดูแล) |
| `HERE()` | ตำแหน่ง GPS ของเครื่องตอนนี้ |
| `LAT(x)` / `LONG(x)` | ดึง "ละติจูด" / "ลองจิจูด" ออกจากพิกัด |
| `LATLONG(lat,long)` | รวม 2 ตัวเลขให้เป็นพิกัดเดียว |
| `DISTANCE(a,b)` | ระยะห่าง 2 จุด **หน่วยกิโลเมตร** |
| `LOOKUP(ค่า, ตาราง, คอลัมน์ผลลัพธ์)` | ค้นแถวที่ตรงกับ "ค่า" แล้วเอาค่าจากคอลัมน์ที่ระบุ |
| `SELECT(...)` | ดึงค่าจากหลายแถว (ใช้ใน SUM/COUNT) |
| `SUM(...)` | รวมยอด |
| `COUNT(...)` | นับจำนวน |
| `FILTER(ตาราง, เงื่อนไข)` | ดึงเฉพาะแถวที่ตรงเงื่อนไข |
| `UNIQUE(...)` | เอาเฉพาะค่าที่ไม่ซ้ำ |
| `LIST(...)` | สร้างรายการ |
| `IFS(เงื่อนไข1, ผล1, ...)` | เลือกคำตอบตามเงื่อนไขแรกที่จริง |
| `IF(เงื่อนไข, ถ้าจริง, ถ้าไม่จริง)` | เลือก 2 ทาง |
| `CONCATENATE(...)` / `&` | ต่อข้อความ |
| `TEXT(ค่า, รูปแบบ)` | แปลงค่าเป็นข้อความตามรูปแบบ (เช่น `"0.0"` = ทศนิยม 1 ตำแหน่ง) |
| `IN(...)` / `NOT(...)` | อยู่ในรายการ / ไม่อยู่ในรายการ |
| `ISBLANK(...)` / `ISNOTBLANK(...)` | ว่าง / ไม่ว่าง |
| `OR(...)` / `AND(...)` | หรือ / และ |
| `ANY(...)` | มีสักค่าหนึ่งในรายการตรงเงื่อนไขไหม |
| `REF_ROWS(ตาราง, คอลัมน์)` | ดึงแถวที่ "อ้างกลับ" มาหากลับ |
| `MINROW(...)` / `MAXROW(...)` | แถวที่เล็ก/ใหญ่ที่สุดตามเงื่อนไข |
| `SORT(...)` / `UNIQUE(LIST(...))` | เรียง / เอาค่าไม่ซ้ำ (ใช้ทำ dropdown) |
| `CONTEXT("ViewType")` | ตอนนี้อยู่หน้าจอแบบไหน (Form/Detail) |
| `NOW()` + `TEXT(...,"DD/MM/YYYY HH:MM")` | สร้างข้อความ "แก้ไขเมื่อ 30/10/2026 14:22" |

## กลุ่มที่ 3 — คำเกี่ยวกับ "หน้าจอและปุ่ม"

| คำ | แปลว่าง่าย ๆ |
|---|---|
| **View** | หน้าจอของแอป (แอปนี้มี 115 หน้าจอ เช่น หน้าฟอร์มกรอก, หน้าตาราง, หน้าแผนที่) |
| **Slice** | "มุมมอง" ของตารางเดียวกันที่กรองข้อมูลต่างกัน (เช่น เฉพาะงานที่รออนุมัติ) |
| **Action** | ปุ่มที่กดแล้วระบบทำอะไรให้อัตโนมัติ (214 ปุ่มในแอปนี้) |
| **Action types** | `ADD_RECORD` เพิ่มแถว · `EDIT_RECORD` เปิดแก้ · `DELETE_RECORD` ลบ · `SET_COLUMN_VALUE` เซ็ตค่าในแถวนี้ · `NAVIGATE_APP` เปิดหน้าจออื่น · `EXPORT_VIEW` export เป็น CSV/XLSX · `EMAIL` ส่งอีเมล · `SMS` ส่ง SMS · `CALL` โทร · `REF_ACTION` เปิดรายการที่อ้างอิง · `COMPOSITE` รวมหลายคำสั่ง |
| **Prominence** | ปุ่มจะโผล่ตรงไหน: `Display_Inline` (ในหน้าจอ) · `Display_Overlay` (ลอยบน) · `Display_Prominently` (เด่นมาก) · `Do_Not_Display` (ซ่อน) |
| **Bulk action?** | กดครั้งเดียวทำกับหลายแถวไหม |
| **Format rule** | กฎเปลี่ยนสี/ตัวหนา/ไอคอนตามเงื่อนไข (11 ข้อในแอปนี้) |
| **Only if this condition is true** | เงื่อนไขที่ต้องจริงถึงจะเห็นปุ่มนั้น |
| **Show_If (ของปุ่ม)** | เหมือนกัน — ควบคุมการแสดงปุ่ม |

## กลุ่มที่ 4 — คำเกี่ยวกับ "บอทและระบบอัตโนมัติ"

| คำ | แปลว่าง่าย ๆ |
|---|---|
| **Bot / บอท** | โปรแกรมที่ทำงานเองตามเวลาหรือเงื่อนไข (เช่น ทุกวัน 6 โมงไปดึงใบวางบิลใหม่) |
| **Event / Trigger** | เหตุการณ์ที่ทำให้บอททำงาน (เช่น "ทุกวันเวลา 6 โมง" หรือ "เมื่อมีแถวใหม่") |
| **Process** | ขั้นตอนการทำงานของบอท 1 ตัว (อาจมีหลายขั้น) |
| **Process Table** | ตารางเก็บ "ตัวแปร" ที่ส่งผ่านขั้นตอนไปขั้นตอนมา (ชั่วคราว) |
| **State Table** | ตารางเก็บ "ตอนนี้อยู่ขั้นตอนไหนแล้ว" (ชั่วคราว) |
| **Step Output** | ผลลัพธ์ของ 1 ขั้นตอน (ชั่วคราว ถูกล้างทุกรอบ) |
| **Clear Output** | ชื่อ Step Output ที่แอปตั้งชื่อให้อัตโนมัติ (เช่น "Clear Output 7") |
| **Ref action / REF_ACTION** | ปุ่มที่เปิดไปหน้าจอของตารางที่อ้างอิง |
| **MD_LINK / MD_ID / MATCH_KEY** | คีย์ฝั่งระบบแผนที่ / การจับคู่แถว — **เป็นคนละกลไกกับการดึงข้อมูลข้ามชีตของแอป** (`SM_Link_SCG` คือตัวที่ชีต SCG ใช้ดึงข้อมูลจริง) |

## กลุ่มที่ 5 — คำเกี่ยวกับ "ไฟล์ในรีโปนี้" (ศัพท์ฝั่ง GitHub/ข้อมูล)

| คำ | แปลว่าง่าย ๆ |
|---|---|
| **Repository / Repo** | โฟลเดอร์โปรเจกต์บน GitHub |
| **Push / Commit** | บันทึกการแก้ไขขึ้น GitHub |
| **CI / Workflow** | งานอัตโนมัติที่รันทุกครั้งที่ push เพื่อตรวจว่าข้อมูลยังถูกต้อง |
| **CSV** | ไฟล์ตารางข้อความ เปิดด้วย Excel ได้ (คั่นด้วยจุลภาค) |
| **JSON** | ไฟล์ข้อมูลแบบมีโครงสร้าง (เหมือนข้อมูล 1 ชิ้น) |
| **Mermaid** | ภาษาเขียน "แผนภาพ" ด้วยข้อความ (ใช้ในไฟล์ .md ให้ GitHub วาดให้) |
| **ERD** | แผนภาพความสัมพันธ์ระหว่างตาราง |
| **anchor** | ข้อความมาร์กเกอร์ซ่อนไว้ในเอกสาร เช่น `<!-- col: ตาราง :: คอลัมน์ -->` ใช้ให้เครื่องตรวจนับได้ว่าอธิบายครบทุกช่องไหม |
| **deterministic** | ทำซ้ำแล้วได้ผลเหมือนเดิมทุกครั้ง (ไม่ใช่การเดา) |
| **needs_review** | ธงที่ติ้งว่า "ค่านี้ควรไปเช็คในแอปอีกครั้ง" |

## คำที่คุณอาจเจอในคำตอบของ AI แต่ไม่รู้ความหมาย

| คำ | แปลว่า / ควรทำอย่างไร |
|---|---|
| "hallucination" | AI แต่งข้อมูลที่ไม่มีจริง → ถามว่า "อ้างอิงไฟล์ไหน" ทุกครั้ง |
| "context window" | ปริมาณข้อความที่ AI อ่านได้ในครั้งเดียว → อย่ายัดทุกอย่าง ให้เลือกเฉพาะไฟล์ที่เกี่ยว |
| "agent" | AI ที่ทำงานหลายขั้นเองได้ (อ่านไฟล์ → วิเคราะห์ → เขียน → ตรวจ) |
| "prompt" | คำสั่งที่คุณให้กับ AI |
| "fine-tune / RAG / fine-grained" | วิธีทำให้ AI "รู้จัก" ข้อมูลเฉพาะ — สำหรับเคสนี้ **ไม่ต้องทำอะไรเลย** แค่ให้ AI อ่านไฟล์ในรีโปก็พอ |
| "token" | หน่วยวัดความยาวข้อความ (ภาษาไทย 1 ตัวอักษร ≈ 1 token) |
