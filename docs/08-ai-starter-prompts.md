# 08 — พรอมต์พร้อมใช้สำหรับ AI อื่น (AI Starter Prompts)

คัดลอก prompt ด้านล่างไปวางใน AI ตัวอื่น (Claude, ChatGPT, Gemini, Cursor, Copilot…)
ที่เปิด repo นี้ไว้ แล้วมันจะรู้ทันทีว่าข้อมูลอยู่ตรงไหน อ่านยังไง และต้องระวังอะไร

> ทุก prompt ด้านล่างตั้งใจให้ **ตอบจากไฟล์ใน repo เท่านั้น**
> ถ้าคำตอบมีตัวเลขหรือข้อเท็จจริงที่ไม่ได้มาจากไฟล์ ให้ถามกลับว่า "ข้อมูลนี้ไม่มีใน repo
> ผมต้องการไฟล์ข้อมูลเพิ่ม" — นี่คือสิ่งที่เราต้องการจริงๆ

---

## 1) เริ่มต้นทั่วไป (วางเป็น system prompt / project instruction)

```
คุณกำลังทำงานกับ repo ชุดข้อมูล AppSheet ของ หจก. เผ่าปัญญา ทรานสปอร์ต (โลจิสติกส์หึบเย็น)
ก่อนตอบคำถามใด ๆ ให้อ่าน AGENTS.md ก่อนเสมอ แล้วใช้ app/tables.csv, app/columns.csv,
app/relations.csv, app/computed_columns.csv, app/actions.csv เป็นแหล่งความจริง

หลักการ:
1. ห้ามเดาค่าของ schema หรือข้อมูลตัวเลขใด ๆ — ถ้าไม่มีในไฟล์ให้บอกว่า "ยังไม่มีข้อมูลส่วนนี้"
2. แยกให้ชัดระหว่าง "ตารางจริง" (29 ตาราง มีข้อมูลธุรกิจ) กับ "ตารางบอท" (60 ตาราง เป็น state machine
   ของ automation) — ดู docs/04-bots-and-automations.md
3. อ้างอิง path ของไฟล์ที่ใช้ทุกครั้ง เช่น (app/columns.csv)
4. ข้อมูลมี PII (ชื่อ-นามสกุล, เบอร์โทร, ทะเบียนรถ, GPS) — ให้ปกปิดหรือรวมกลุ่ม
   เว้นแต่ผู้ใช้ขอเจาะจง
5. ถ้าตอบแล้วต้องรู้ว่าใช้ข้อมูลจริงจากไหน ให้บอกด้วย
```

---

## 2) สรุปโครงสร้างข้อมูล

```
อ่าน app/meta.json, app/tables.csv แล้วสรุปให้ผมว่า:
- แอปนี้เก็บข้อมูลอะไรบ้าง (แยกตารางธุรกิจ 29 ตารางออกมา)
- ตารางธุรกิจแต่ละกลุ่มทำหน้าที่อะไร
- ตารางไหนเป็นแกนกลาง (fact table) ตารางไหนเป็นข้อมูลประกอบ (dimension)
- จุดที่ควรระวังในการวิเคราะห์

อ้างอิงชื่อไฟล์และชื่อตารางจริงทุกครั้ง
```

---

## 3) วิเคราะห์สูตรคิดราคา

```
จาก app/computed_columns.csv และ docs/03-formulas.md อธิบายให้ฟังว่า:
- ราคาที่เกิดกับงานหนึ่งงานคำนวณจากอะไรบ้าง (รายการที่บวกเข้า/ลบออก)
- มีจุดไหนที่ราคาถูกปรับด้วยเงื่อนไข (เช่น เติมน้ำมัน, จุดเพิ่ม, ระยะทาง)
- ถ้าอยากตรวจสอบราคาของงานในเดือนก่อน ต้องดูคอลัมน์ไหนบ้าง

ถ้าส่วนไหนข้อมูลไม่พอให้บอกตรง ๆ ว่าไม่มี
```

---

## 4) หางานที่ค้าง / งานที่ผิดปกติ

```
ช่วยออกแบบ query สำหรับหา "งานที่ค้างสแกน" และ "งานที่ราคาไม่ตรง" จาก schema ที่มี
อธิบายว่าต้อง join ตารางไหนบ้าง ใช้คอลัมน์ไหนเป็นเงื่อนไข และเขียนโค้ด pandas ให้รันได้จริง
(อ้างอิง app/columns.csv และ app/relations.csv เป็นหลัก)
```

---

## 5) เช็คคุณภาพข้อมูล

```
ตรวจคุณภาพข้อมูลของแอปนี้จาก schema ที่มี แล้วบอกว่า:
- คอลัมน์ไหนเป็น key / part of key และมีความเสี่ยงเรื่องความไม่ unique หรือไม่
- คอลัมน์ไหนเป็น PII ที่ต้องปกปิด
- จุดไหนที่ Valid_If / Required_If บังคับความสมบูรณ์
- ถ้าจะทำ data profiling เมื่อไหร่ ควรโฟกัสที่ตารางไหนก่อน
```

---

## 6) ออกแบบเพิ่มฟิลด์ใหม่ (ต้องเข้าใจก่อนว่า AppSheet ทำอะไรได้)

```
ผมอยากเพิ่มฟิลด์ "<ชื่อฟิลด์>" เข้าตาราง "<ชื่อตาราง>" ในแอปนี้
ช่วยอ่าน schema ของตารางนั้น (app/columns.csv + docs/01a-data-dictionary-business.md)
แล้วออกแบบ: ชนิดข้อมูล, สูตร, Valid_If, key, ความสัมพันธ์ Ref และผลกระทบต่อตารางอื่น
ระบุด้วยว่าอะไรในข้อเสนอนี้ AppSheet ทำได้จริงและอะไรต้องทำที่ Google Sheet
```

---

## 7) ตรวจงานของทีมอื่น (code review บนโค้ดที่เกี่ยวกับข้อมูล)

```
อ่าน scripts/ ทั้งหมด แล้วตรวจว่า:
- ตัวแยก PDF (extract_appsheet.py) มีจุดที่อาจตกหล่นข้อมูลหรือแตกค่าผิดหรือไม่
  โดยเทียบกับตัวเลขที่ PDF ประกาศ (app/meta.json)
- ตัวตรวจ (validate_repo.py) ครอบคลุมกรณีที่จะทำให้เอกสารไม่ครบหรือไม่
- สคริปต์ดึงข้อมูล (pull_data.py) มีความเสี่ยงเรื่องข้อมูลส่วนบุคคลหรือข้อมูลตกหล่นไหม
```

---

## 8) ตั้งค่าให้ AI อ่าน repo นี้เป็น "โปรเจกต์" (สำหรับ Claude Code / Cursor / Codex)

สร้างไฟล์ `CLAUDE.md` หรือ `.cursorrules` ในโฟลเดอร์ repo ด้วยเนื้อหา:

```
อ่าน AGENTS.md ก่อนเริ่มงานทุกครั้ง
ใช้ app/ เป็นแหล่งความจริงของ schema ห้ามเดา
เอกสารอยู่ใน docs/ — ถ้าต้องแก้เอกสารให้รัน python3 scripts/validate_repo.py หลังแก้
ห้ามแก้ไฟล์ใน app/ ด้วยมือ — ต้องแก้ที่ scripts/extract_appsheet.py แล้วรันใหม่
ข้อมูลใน data/ มี PII ห้ามส่งออกนอกองค์กรโดยไม่มีคำสั่งจากผู้ใช้
```

---

## หมายเหตุสำคัญเรื่องความครบถ้วนของข้อมูล

| ส่วน | สถานะ |
|---|---|
| โครงสร้างตาราง/คอลัมน์/สูตร/ความสัมพันธ์ | ✅ ครบ 100% (ตรงกับที่ PDF ประกาศ) |
| ข้อมูลระดับแถว (rows) | ⏳ ยังไม่มี — รอ export จาก AppSheet/Google Sheets ตาม `data/README.md` |
| นิยามบอท/automation (event, webhook, schedule) | ⚠️ ไม่มีใน PDF — ต้องไปดึงจาก AppSheet → Automations → Bots |

พอมี row data แล้ว ให้รัน `python3 scripts/validate_repo.py` อีกครั้ง แล้ว prompt ข้อ 4-5
จะตอบได้จริงด้วยตัวเลขจริงจากธุรกิจ
