# Format Rule: สแกนรับแล้ว

<!-- rule: สแกนรับแล้ว -->

| คุณสมบัติ | ค่า |
|---|---|
| ใช้กับข้อมูล | `ตารางงานประจำวัน` |
| คอลัมน์/แอ็กชันที่กระทบ | `Invoice No ScanStatus ชื่อเจ้าของสินค้า_Invoice_ที่ต้องสแกน` |
| เงื่อนไข | `=[ScanStatus] = "สแกนรับแล้ว"` |
| ลำดับกติกา | 1 |
| ปิดใช้งาน | `No` |
| แสดงใน UI | `ALWAYS` |
