# Format Rule: แจ้งเตือนเช็คราคาแล้วปกติ

<!-- rule: แจ้งเตือนเช็คราคาแล้วปกติ -->

| คุณสมบัติ | ค่า |
|---|---|
| ใช้กับข้อมูล | `ข้อมูลการวางบิล` |
| คอลัมน์/แอ็กชันที่กระทบ | `ราคาในระบบหลังส่งสินค้า` |
| เงื่อนไข | `=IF([ราคาในระบบหลังส่งสินค้า] = [ราคา], TRUE, FALSE)` |
| ลำดับกติกา | 1 |
| ปิดใช้งาน | `No` |
| แสดงใน UI | `ALWAYS` |

## รูปแบบที่ใช้

```json
"{\"textColor\": \"green\", \"highlightColor\": \"green\", \"textSize\": 1.2, \"underline\": false, \"strikethrough\": false, \"bold\": true, \"italic\": false, \"uppercase\": false, \"icon\": null, \"imageSize\": null}"
```
