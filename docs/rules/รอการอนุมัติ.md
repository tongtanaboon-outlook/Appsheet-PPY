# Format Rule: รอการอนุมัติ

<!-- rule: รอการอนุมัติ -->

| คุณสมบัติ | ค่า |
|---|---|
| ใช้กับข้อมูล | `ข้อมูลการวางบิล` |
| คอลัมน์/แอ็กชันที่กระทบ | `ราคา สถานะการอนุมัติ` |
| เงื่อนไข | `=[สถานะการอนุมัติ] = "รอการอนุมัติ"` |
| ลำดับกติกา | 1 |
| ปิดใช้งาน | `No` |
| แสดงใน UI | `ALWAYS` |
