# Format Rule: แจ้งเตือนราคาหลังวิ่งงาน

<!-- rule: แจ้งเตือนราคาหลังวิ่งงาน -->

| คุณสมบัติ | ค่า |
|---|---|
| ใช้กับข้อมูล | `ข้อมูลการวางบิล` |
| คอลัมน์/แอ็กชันที่กระทบ | `ราคาในระบบหลังส่งสินค้า` |
| เงื่อนไข | `=AND( [ราคาในระบบหลังส่งสินค้า] <> [ราคา], OR( [ชื่องาน] = "นครหลวง", [ชื่องาน] = "โอนคลัง พว", [ชื่องาน] = "โอนคลัง นำ วิวัฒน์", [ชื่องาน] = "โอนคลัง ซอยฮะ (โกเรีย)", [ชื่องาน] = "โอน คลัง TRW", [ชื่องาน] = "โอนคลัง NocNoc", [ชื่องาน] = "โอนคลัง CPF FOOD", [ชื่องาน] = "โอนคลัง BYD", [ชื่องาน] = "ภูมิภาค" ) )` |
| ลำดับกติกา | 1 |
| ปิดใช้งาน | `No` |
| แสดงใน UI | `ALWAYS` |
