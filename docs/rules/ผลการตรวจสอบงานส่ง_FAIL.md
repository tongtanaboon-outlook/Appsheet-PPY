|---|---|
| ใช้กับข้อมูล | `SCGนครหลวงJWDภูมิภาค` |
| คอลัมน์/แอ็กชันที่กระทบ | `ระยะขยับจากจุดเริ่มต้น_เมตร ระยะเวลาใช้งาน_นาที ความเร็วการเคลื่อนที่_เมตร_นาที ผลการตรวจสอบงานส่ง เหตุผิดปกติที่ตรวจพบ` |
| เงื่อนไข | `=[ผลการตรวจสอบงานส่ง] = "FAIL"` |
| ลำดับกติกา | 1 |
| ปิดใช้งาน | `No` |
| แสดงใน UI | `ALWAYS` |
