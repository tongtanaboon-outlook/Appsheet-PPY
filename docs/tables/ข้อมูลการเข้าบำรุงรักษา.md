# ข้อมูลการเข้าบำรุงรักษา

<!-- table: ข้อมูลการเข้าบำรุงรักษา -->

> **ตารางธุรกิจ** — มีข้อมูลจริงอยู่ใน Google Sheet `ข้อมูลการเข้าบำรุงรักษา`

| คุณสมบัติ | ค่า |
|---|---|
| ชนิดตาราง | ตารางจริง (business) |
| ที่มาข้อมูล | `google` |
| จำนวนคอลัมน์ | 14 |
| Key | `ID_การเข้าบำรุงรักษา` |
| คอลัมน์คำนวณอัตโนมัติ | 7 |
| เห็นใน UI | `ALWAYS` |
| Security filter | `=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())` |
| สิทธิ์แก้ไข | `ALL_CHANGES` |

## สูตรในตารางนี้

### ID_การเข้าบำรุงรักษา

<!-- formula: ข้อมูลการเข้าบำรุงรักษา :: ID_การเข้าบำรุงรักษา -->

**ค่าเริ่มต้น**

```
UNIQUEID()
```

- **Reset_If**: `No`

### วันที่เข้าบำรุงรักษา

<!-- formula: ข้อมูลการเข้าบำรุงรักษา :: วันที่เข้าบำรุงรักษา -->

**ค่าเริ่มต้น**

```
=NOW()
```

- **Editable_If**: `=USERROLE() ="ADMIN"`
- **Reset_If**: `No`

### ชื่อ - นามสกุล

<!-- formula: ข้อมูลการเข้าบำรุงรักษา :: ชื่อ - นามสกุล -->

**ค่าเริ่มต้น**

```
=[ID_พนักงาน].[ชื่อ - นามสกุล]
```

- **Reset_If**: `No`

### ทะเบียนรถ

<!-- formula: ข้อมูลการเข้าบำรุงรักษา :: ทะเบียนรถ -->

**ค่าเริ่มต้น**

```
=[ID_พนักงาน].[ทะเบียนรถ]
```

- **Reset_If**: `No`

### Email พนักงาน

<!-- formula: ข้อมูลการเข้าบำรุงรักษา :: Email พนักงาน -->

**ค่าเริ่มต้น**

```
=USEREMAIL()
```

- **Editable_If**: `=USERROLE() ="ADMIN"`
- **Reset_If**: `No`

### เดือน

<!-- formula: ข้อมูลการเข้าบำรุงรักษา :: เดือน -->

**ค่าเริ่มต้น**

```
=IF( ISBLANK([วันที่เข้าบำรุงรักษา]), "", CONCATENATE( YEAR([วัน ที่เข้าบำรุงรักษา]) - IF(YEAR([วันที่เข้าบำรุงรักษา]) > 2500, 543, 0), "-", TEXT([วันที่เข้าบำรุงรักษา], "MM") ) )
```

- **Reset_If**: `No`

### ID_พนักงาน

<!-- formula: ข้อมูลการเข้าบำรุงรักษา :: ID_พนักงาน -->

**ค่าเริ่มต้น**

```
=LOOKUP(USEREMAIL(), "ข้อมูลพนักงาน", "Email พนักงาน", "ID_พนักงาน")
```

- **Editable_If**: `=USERROLE() ="ADMIN"`
- **Show_If**: `=USERROLE() ="ADMIN"`
- **Reset_If**: `No`

## ความสัมพันธ์

**อ้างอิงออกไป** (คอลัมน์ของตารางนี้ → ตารางอื่น)

- `ID_พนักงาน` → `ข้อมูลพนักงาน` (key: `ID_พนักงาน`)
