|---|---|
| ชนิดตาราง | ตารางจริง (business) |

## สูตรในตารางนี้

### ID_สร้างเอกสาร

<!-- formula: สร้างเอกสาร :: ID_สร้างเอกสาร -->

**ค่าเริ่มต้น**

```
UNIQUEID()
```

- **Reset_If**: `No`

### ราคารวม

<!-- formula: สร้างเอกสาร :: ราคารวม -->

**App formula**

```
=SUM(SELECT(ข้อมูลการวางบิล[ราคา], AND([ชื่องาน]= [_THISROW].[ชื่องาน],[วันที่] >= [_THISROW].[Startdate], [วันที่] <= [_THISROW].[Enddate])))
```
