## สูตรในตารางนี้

### เดือน

<!-- formula: ราคาในระบบก่อนส่งสินค้า :: เดือน -->

**App formula**

```
=IF( ISBLANK([วันที่ส่งสินค้า]), "", CONCATENATE( YEAR([วันที่ส่ง สินค้า]) - IF(YEAR([วันที่ส่งสินค้า]) > 2500, 543, 0), "-", TEXT([วันที่ ส่งสินค้า], "MM") ) )
```

- **Reset_If**: `No`

## ความสัมพันธ์

- ไม่มีคอลัมน์ Ref ที่ชี้ออกไปยังตารางอื่น

- ไม่มีตารางอื่นอ้างอิงกลับมา
