## สูตรในตารางนี้

### ID_ปริ๊นใบวางบิล

<!-- formula: ปริ๊นใบวางบิล :: ID_ปริ๊นใบวางบิล -->

**ค่าเริ่มต้น**

```
UNIQUEID()
```

- **Reset_If**: `No`

### ราคารวม

<!-- formula: ปริ๊นใบวางบิล :: ราคารวม -->

**App formula**

```
=SUM(SELECT(ข้อมูลการวางบิล[ราคา], AND([ชื่องาน]= [_THISROW].[ชื่องาน],[วันที่] >= [_THISROW].[Startdate], [วันที่] <= [_THISROW].[Enddate])))
```

- **Reset_If**: `No`

### ผลลัพท์

<!-- formula: ปริ๊นใบวางบิล :: ผลลัพท์ -->

**App formula**

```
=FILTER("ข้อมูลการวางบิล",(AND([ชื่องาน]=[_THISROW].[ชื่องาน], [วันที่]>=[_THISROW].[StartDate],[วันที่]<=[_THISROW]. [EndDate])))
```

- **Reset_If**: `No`
