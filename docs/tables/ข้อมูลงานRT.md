## สูตรในตารางนี้

### ID_RT

<!-- formula: ข้อมูลงานRT :: ID_RT -->

**ค่าเริ่มต้น**

```
=UNIQUEID()
```

- **Reset_If**: `No`

### เดือน

<!-- formula: ข้อมูลงานRT :: เดือน -->

**App formula**

```
=IF( ISBLANK([วันที่เข้ารับ]), "", CONCATENATE( YEAR([วันที่เข้า รับ]) - IF(YEAR([วันที่เข้ารับ]) > 2500, 543, 0), "-", TEXT([วันที่เข้ารับ], "MM") ) )
```

- **Reset_If**: `No`

### Related แจ้งปั ญหาระหว่างวันs

<!-- formula: ข้อมูลงานRT :: Related แจ้งปั ญหาระหว่างวันs -->

**App formula**

```
=REF_ROWS("แจ้งปั ญหาระหว่างวัน", "RT_Link")
```

- **Reset_If**: `No`
