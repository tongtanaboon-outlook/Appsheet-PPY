## สูตรในตารางนี้

### SummaryKey

<!-- formula: สรุป_เจ้าของสินค้า :: SummaryKey -->

**ค่าเริ่มต้น**

```
=UNIQUEID()
```

- **Reset_If**: `No`
- **Error_Message_If_Invalid**: `=UNIQUEID()`

### LastUpdated

<!-- formula: สรุป_เจ้าของสินค้า :: LastUpdated -->

**ค่าเริ่มต้น**

```
=NOW()
```

- **Reset_If**: `No`

### รายการ_ทั้งหมด

<!-- formula: สรุป_เจ้าของสินค้า :: รายการ_ทั้งหมด -->

**App formula**

```
=FILTER( "ตารางงานประจำวัน", AND( [ชื่อเจ้าของสินค้า] = [_THISROW].[SoldToName], [Plan Delivery] = [_THISROW]. [PlanDelivery] ) )
```

- **Reset_If**: `No`

### รายการ_สแกนแล้ว

<!-- formula: สรุป_เจ้าของสินค้า :: รายการ_สแกนแล้ว -->

**App formula**

```
=FILTER( "ตารางงานประจำวัน", AND( [ชื่อเจ้าของสินค้า] = [_THISROW].[SoldToName], [Plan Delivery] = [_THISROW]. [PlanDelivery], [ScanStatus] = "สแกนรับแล้ว" ) )
```

- **Reset_If**: `No`

### รายการ_รอสแกน

<!-- formula: สรุป_เจ้าของสินค้า :: รายการ_รอสแกน -->

**App formula**

```
=FILTER( "ตารางงานประจำวัน", AND( [ชื่อเจ้าของสินค้า] = [_THISROW].[SoldToName], [Plan Delivery] = [_THISROW]. [PlanDelivery], OR( ISBLANK([ScanStatus]), [ScanStatus] <> "สแกนรับแล้ว" ) ) )
```

- **Reset_If**: `No`

### จำนวน_สแกนแล้ว

<!-- formula: สรุป_เจ้าของสินค้า :: จำนวน_สแกนแล้ว -->

**App formula**

```
=COUNT( UNIQUE( SELECT( ตารางงานประจำวัน[Invoice No], AND( [ชื่อเจ้าของสินค้า] = [_THISROW].[SoldToName], [Plan Delivery] = [_THISROW].[PlanDelivery], [ScanStatus] = "สแกนรับ แล้ว" ) ) ) )
```

- **Reset_If**: `No`

### จำนวน_รอสแกน

<!-- formula: สรุป_เจ้าของสินค้า :: จำนวน_รอสแกน -->

**App formula**

```
=[จำนวน_ทั้งหมด]-[จำนวน_สแกนแล้ว]
```

- **Reset_If**: `No`

### สรุปยอด

<!-- formula: สรุป_เจ้าของสินค้า :: สรุปยอด -->

**App formula**

```
=IF( [จำนวน_E-POD_ทั้งหมด] > 0, " 𝐄 ─ 𝐃 " & [จำนวน_EPOD_ทั้งหมด], " " & [จำนวน_ทั้งหมด] & " "& [จำนวน_สแกนแล้ว] & " " & [จำนวน_รอสแกน] )
```

- **Reset_If**: `No`

## ความสัมพันธ์

- ไม่มีคอลัมน์ Ref ที่ชี้ออกไปยังตารางอื่น

- ไม่มีตารางอื่นอ้างอิงกลับมา
