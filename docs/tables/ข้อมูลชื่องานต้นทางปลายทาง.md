# ข้อมูลชื่องานต้นทางปลายทาง

<!-- table: ข้อมูลชื่องานต้นทางปลายทาง -->

> **ตารางธุรกิจ** — มีข้อมูลจริงอยู่ใน Google Sheet `ข้อมูลชื่องานต้นทางปลายทาง`

| คุณสมบัติ | ค่า |
|---|---|
| ชนิดตาราง | ตารางจริง (business) |
| ที่มาข้อมูล | `google_tables` |
| จำนวนคอลัมน์ | 9 |
| Key | `ID_ชื่องาน` |
| คอลัมน์คำนวณอัตโนมัติ | 2 |
| เห็นใน UI | `ALWAYS` |
| สิทธิ์แก้ไข | `ALL_CHANGES` |

| 3 | `ID_ชื่องาน` | Text | คอลัมน์ข้อความ — **Key ของแถว**; มีค่าเริ่มต้นเมื่อสร้างแถว | `=UNIQUEID()` | ✅ | — |
| 4 | `ชื่องาน` | Text | คอลัมน์ข้อความ | — |  | — |
| 5 | `สถานที่รับสินค้า (ต้นทาง)` | Text | คอลัมน์ข้อความ | — |  | — |
| 6 | `สถานที่ส่งสินค้า (ปลายทาง)` | Text | คอลัมน์ข้อความ | — |  | — |
| 7 | `ประเภทการคำนวน` | Enum | คอลัมน์ตัวเลือกเดียว | — |  | — |
| 8 | `ระยะทางคงที่` | Decimal | คอลัมน์ทศนิยม | — |  | — |
| 9 | `ราคาคงที่` | Decimal | คอลัมน์ทศนิยม | — |  | — |

## สูตรในตารางนี้

### Row ID

<!-- formula: ข้อมูลชื่องานต้นทางปลายทาง :: Row ID -->

**ค่าเริ่มต้น**

```
UNIQUEID("PackedUUID")
```

- **Reset_If**: `No`

### ID_ชื่องาน

<!-- formula: ข้อมูลชื่องานต้นทางปลายทาง :: ID_ชื่องาน -->

**ค่าเริ่มต้น**

```
=UNIQUEID()
```

- **Reset_If**: `No`
