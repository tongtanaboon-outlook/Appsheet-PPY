## สูตรในตารางนี้

### ID_งานประจำวัน

<!-- formula: ตารางงานประจำวัน :: ID_งานประจำวัน -->

**ค่าเริ่มต้น**

```
=UNIQUEID()
```

- **Reset_If**: `No`

### จำนวนปลายทาง

<!-- formula: ตารางงานประจำวัน :: จำนวนปลายทาง -->

**App formula**

```
=COUNT( UNIQUE( SELECT( ตารางงานประจำวัน[ชื่อปลายทาง], [Shipment No] = [_THISROW].[Shipment No] ) ) )
```

- **Reset_If**: `No`

### ลำดับแรก

<!-- formula: ตารางงานประจำวัน :: ลำดับแรก -->

**App formula**

```
=[_ROWNUMBER] = MIN( SELECT( ตารางงานประจำ วัน[_ROWNUMBER], [Shipment No] = [_THISROW].[Shipment No], ) )
```

- **Reset_If**: `No`

### จำนวนจุดที่ส่งจริง

<!-- formula: ตารางงานประจำวัน :: จำนวนจุดที่ส่งจริง -->

**App formula**

```
=COUNT( SELECT( SCGนครหลวงJWDภูมิภาค[Shipment No], [Shipment No] = [_THISROW].[Shipment No]) )
```

- **Reset_If**: `No`

### เดือน

<!-- formula: ตารางงานประจำวัน :: เดือน -->

**App formula**

```
=IF( ISBLANK([Plan Delivery]), "", CONCATENATE( YEAR([Plan Delivery]) - IF(YEAR([Plan Delivery]) > 2500, 543, 0), "-", TEXT([Plan Delivery], "MM") ) )
```

- **Reset_If**: `No`

### Related SCGนครหลวงJWDภูมิภาคs

<!-- formula: ตารางงานประจำวัน :: Related SCGนครหลวงJWDภูมิภาคs -->

**App formula**

```
=REF_ROWS("SCGนครหลวงJWDภูมิภาค", "SM_Link_SCG")
```

- **Reset_If**: `No`

### Related แจ้งปั ญหาระหว่างวันs

<!-- formula: ตารางงานประจำวัน :: Related แจ้งปั ญหาระหว่างวันs -->

## ความสัมพันธ์

- ไม่มีคอลัมน์ Ref ที่ชี้ออกไปยังตารางอื่น

- `ScanDocs`.`Invoice_No` → `ตารางงานประจำวัน`
- `Process for Telegram_แจ้งปั ญหา - 1 Process Table`.`SM_Link` → `ตารางงานประจำวัน`
- `Process for AppSheet_KM - 1 Process Table`.`SM_Link_SCG` → `ตารางงานประจำวัน`
- `New step Output 2`.`SM_Link_SCG` → `ตารางงานประจำวัน`
- `Process for New bot - 1 Process Table`.`SM_Link` → `ตารางงานประจำวัน`
- `New step Output 3`.`SM_Link` → `ตารางงานประจำวัน`
- `Process for Update ScanStatus เมื่อสแกน Invoice - 1 Process Table`.`Invoice_No` → `ตารางงานประจำวัน`
- `Update Output`.`Invoice_No` → `ตารางงานประจำวัน`
