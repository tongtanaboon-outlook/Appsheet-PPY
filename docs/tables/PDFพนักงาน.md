## สูตรในตารางนี้

### ID_XLSXพนักงาน

<!-- formula: PDFพนักงาน :: ID_XLSXพนักงาน -->

**ค่าเริ่มต้น**

```
UNIQUEID()
```

- **Reset_If**: `No`

### ราคารวม

<!-- formula: PDFพนักงาน :: ราคารวม -->

**App formula**

```
=SUM(SELECT(ข้อมูลการวางบิล[ราคา], AND([ชื่อ - นามสกุล]= [_THISROW].[ชื่อ - นามสกุล],[วันที่] >= [_THISROW].[Startdate], [วัน ที่] <= [_THISROW].[Enddate])))
```

- **Reset_If**: `No`

### ผลลัพท์.

<!-- formula: PDFพนักงาน :: ผลลัพท์. -->

**App formula**

```
=FILTER("ข้อมูลการวางบิล",(AND([ชื่อ - นามสกุล]=[_THISROW].[ชื่อ - นามสกุล],[วันที่]>=[_THISROW].[StartDate],[วันที่]<=[_THISROW]. [EndDate])))
```

- **Reset_If**: `No`

### debugstartdate

<!-- formula: PDFพนักงาน :: debugstartdate -->

**App formula**

```
=[StartDate]
```

- **Reset_If**: `No`

### debugenddate

<!-- formula: PDFพนักงาน :: debugenddate -->

**App formula**

```
=[EndDate]
```

- **Reset_If**: `No`
