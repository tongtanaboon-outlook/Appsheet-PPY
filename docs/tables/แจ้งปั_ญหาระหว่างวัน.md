# แจ้งปั ญหาระหว่างวัน

<!-- table: แจ้งปั ญหาระหว่างวัน -->

> **ตารางธุรกิจ** — มีข้อมูลจริงอยู่ใน Google Sheet `แจ้งปั ญหาระหว่างวัน`

| คุณสมบัติ | ค่า |
|---|---|
| ชนิดตาราง | ตารางจริง (business) |
| ที่มาข้อมูล | `google` |
| จำนวนคอลัมน์ | 29 |
| Key | `ID_แจ้งปั ญหาระหว่างวัน` |
| คอลัมน์คำนวณอัตโนมัติ | 18 |
| เห็นใน UI | `ALWAYS` |
| Security filter | `=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())` |
| สิทธิ์แก้ไข | `ALL_CHANGES` |

## สูตรในตารางนี้

### ID_แจ้งปั ญหาระหว่างวัน

<!-- formula: แจ้งปั ญหาระหว่างวัน :: ID_แจ้งปั ญหาระหว่างวัน -->

**ค่าเริ่มต้น**

```
UNIQUEID()
```

- **Reset_If**: `No`

### กดปุ่ มนี้เพื่อส่งข้อมูลแจ้งปั ญหา

<!-- formula: แจ้งปั ญหาระหว่างวัน :: กดปุ่ มนี้เพื่อส่งข้อมูลแจ้งปั ญหา -->

**ค่าเริ่มต้น**

```
=false
```

- **Valid_If**: `=OR( ISBLANK([กดปุ่ มนี้เพื่อส่งข้อมูลแจ้งปั ญหา]), NOT([กดปุ่ มนี้เพื่อส่งข้อมูลแจ้งปั ญหา]) )`
- **Show_If**: `=AND( ISNOTBLANK([รูป1]), ISNOTBLANK([รูป2]), ISNOTBLANK([รูป3]), NOT([กดปุ่ มนี้เพื่อส่งข้อมูลแจ้งปั ญหา]) )`
- **Reset_If**: `No`
