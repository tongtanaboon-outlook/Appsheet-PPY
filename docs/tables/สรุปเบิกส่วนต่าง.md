## สูตรในตารางนี้

### ID_สรุปเบิกส่วนต่าง

<!-- formula: สรุปเบิกส่วนต่าง :: ID_สรุปเบิกส่วนต่าง -->

**ค่าเริ่มต้น**

```
UNIQUEID()
```

- **Reset_If**: `No`

### สรุป_ทำเบิกส่วนต่างScgวังน้อย

<!-- formula: สรุปเบิกส่วนต่าง :: สรุป_ทำเบิกส่วนต่างScgวังน้อย -->

**App formula**

```
=FILTER( ทำเบิกส่วนต่างSCGวังน้อย, AND(ISNOTBLANK([วันที่ส่ง สินค้า]), [วันที่ส่งสินค้า] >= [_THISROW].[วันที่เริ่มต้น], [วันที่ส่งสินค้า] <= [_THISROW].[วันที่สิ้นสุด], [สถานะ] = "ผ่านการตรวจสอบ" ) )
```

- **Reset_If**: `No`

```
=SUM(SELECT( ทำเบิกส่วนต่างScgวังน้อย[ขออนุมัติเบิกค่าขนส่ง ส่วนเพิ่ม], AND(ISNOTBLANK([วันที่ส่งสินค้า]), [วันที่ส่งสินค้า] >= [_THISROW].[วันที่เริ่มต้น], [วันที่ส่งสินค้า] <= [_THISROW].[วันที่สิ้น สุด], [สถานะ] = "ผ่านการตรวจสอบ" ) ))
```

- **Reset_If**: `No`
