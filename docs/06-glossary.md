# 05 — อภิธานศัพท์ (Glossary)

ศัพท์ที่ใช้จริงในแอปนี้ อ้างอิงจาก **ชื่อคอลัมน์ / ชื่อตาราง / ค่าคงที่ (enum) ที่มีอยู่ใน `app/columns.csv`**
ไม่มีการแต่งคำศัพท์ที่ไม่มีในระบบ

---

## งาน / บิล / การจัดส่ง

| ศัพท์ไทย | ศัพท์อังกฤษ | ความหมาย / ที่มา |
|---|---|---|
| ชื่องาน | Job Name | ชื่อคิวงานของลูกค้า (ตาราง `ข้อมูลชื่องานต้นทางปลายทาง`, คอลัมน์ `ชื่องาน`) |
| ชื่อ - นามสกุล | Full Name | ชื่อ-นามสกุลของพนักงาน/ผู้รับเหมา (คอลัมน์ `ชื่อ - นามสกุล`) |
| ทะเบียนรถ | Truck License / Vehicle Plate | ทะเบียนรถที่ใช้ขนส่ง (คอลัมน์ `ทะเบียนรถ`) |
| Invoice No | Invoice Number | เลขใบวางบิล — คีย์เชิงธุรกิจของหนึ่งงาน (คอลัมน์ `Invoice No`, ชนิด `EnumList`) |
| Shipment No | Shipment Number | เลขชิปเมนต์/รอบการจัดส่ง (คอลัมน์ `Shipment No`) |
| รหัสลูกค้า | Customer ID | รหัสลูกค้าที่ผูกกับงาน (คอลัมน์ `รหัสลูกค้า`) |
| ชื่อเจ้าของสินค้า | Consignor / Shipper | ผู้ส่งสินค้า (คอลัมน์ `ชื่อเจ้าของสินค้า`) |
| ชื่อปลายทาง | Receiver Name | ผู้รับสินค้า (คอลัมน์ `ชื่อปลายทาง`) |
| ที่อยู่ปลายทาง | Destination Address | ที่อยู่จัดส่ง (คอลัมน์ `ที่อยู่ปลายทาง`) |
| จุดส่งสินค้าปลายทาง | Delivery Point (LatLong) | พิกัดจุดส่งสินค้า ชนิด `LatLong` (คอลัมน์ `จุดส่งสินค้าปลายทาง`) |
| พิกัดตอนกดบันทึกงาน | Save-time GPS | พิกัดที่ถูกบันทึกตอนกดบันทึกงาน (`=HERE()`) |
| ระยะทางจากคลัง_Km | Distance from Warehouse (km) | ระยะทางจากคลังสินค้าเป็นกิโลเมตร |
| ระยะขยับจากจุดเริ่มต้น_เมตร | Displacement from Start (m) | ระยะทางที่เคลื่อนที่จริงจากจุดเริ่มต้น คำนวณด้วย `DISTANCE()` |
| ระยะเวลาใช้งาน_นาที | Duration (min) | เวลาที่ใช้ในการส่ง คำนวณจาก `เวลาที่ส่งสินค้า` → `เวลาบันทึกงานสำเร็จ` |
| ความเร็วการเคลื่อนที่_เมตร_นาที | Speed (m/min) | ความเร็วเฉลี่ย = ระยะขยับ ÷ เวลาใช้งาน |

## สแกน / หลักฐานการส่ง

| ศัพท์ไทย | ศัพท์อังกฤษ | ความหมาย / ที่มา |
|---|---|---|
| สแกนรับ | Proof of Delivery scan | การสแกนรับสินค้าที่ปลายทาง (ตาราง `ScanDocs`) |
| ScanStatus | Scan Status | สถานะการสแกน ค่าที่มี: `รอสแกน` / `คลังตัดสินค้า` / `สแกนรับแล้ว` |
| Scan_Method | Scan Method | วิธีสแกน ค่าที่มี: `Barcode` / `Manual` |
| รูปถ่ายบิลส่งสินค้า | Delivery Bill Photo | รูปใบวางบิลตอนส่ง (ชนิด `Image`) |
| รูปสินค้าตอนส่ง | Cargo Photo | รูปสินค้าตอนส่ง |
| รูปหน้าร้าน / บ้าน | Storefront Photo | รูปหน้าร้าน/บ้านผู้รับ ใช้ยืนยันว่าถึงจุดหมายจริง |
| จำนวน_สแกนแล้ว | Scanned Count | จำนวนใบวางบิลที่สแกนแล้ว (คำนวณ `COUNT(UNIQUE(SELECT(...)))`) |
| จำนวน_รอสแกน | Pending Scan Count | จำนวนที่ยังรอสแกน = ทั้งหมด − สแกนแล้ว |
| ยืนยันการกรอกข้อมูล | Data Verification | สถานะการตรวจสอบข้อมูล ค่าที่มี: `ไม่ได้ตรวจสอบ` / `ตรวจสอบข้อมูลเรียบร้อย` |
| ผลการตรวจสอบงานส่ง | Delivery QA Result | ผลตรวจคุณภาพการส่ง ค่าที่มี: `PASS` / `WARNING` / `FAIL` (คำนวณด้วย `IFS()`) |
| เหตุผิดปกติที่ตรวจพบ | Detected Anomalies | รายการความผิดปกติที่ระบบตรวจเจอ (เช่น มีการเคลื่อนที่จากจุดเริ่มต้น / ใช้เวลานานกว่าปกติ / ความเร็วผิดปกติ) |

## ราคา / ค่าเที่ยว / การเบิก

| ศัพท์ไทย | ศัพท์อังกฤษ | ความหมาย / ที่มา |
|---|---|---|
| เรทดีเซล | Diesel Rate | ค่าน้ำมันดีเซล (คอลัมน์ `เรทดีเซล`) |
| ราคา | Price | ราคารวมของงาน |
| ราคารวม | Total Price | ราคารวม (คอลัมน์ `ราคารวม`) |
| ราคาตามระยะทาง | Distance-based Price | ราคาที่คิดจากระยะทาง (คอลัมน์ `ราคาตามระยะทาง`) |
| ราคาจุดเพิ่ม | Stop Fee | ค่าเพิ่มต่อจุดส่ง (คอลัมน์ `ราคาจุดเพิ่ม`) |
| ราคาในระบบก่อนส่งสินค้า | Price in System (before delivery) | ราคาที่ระบบคิดไว้ก่อนส่ง ใช้เทียบกับราคาจริงหลังส่ง |
| ราคาในระบบหลังส่งสินค้า | Price in System (after delivery) | ราคาที่ระบบคิดหลังส่ง |
| ราคาหลังส่งสินค้า / ราคาก่อนส่งสินค้า | Actual price after / before delivery | ราคาจริงที่พนักงานกรอก |
| ราคาที่อนุมัติแล้ว | Approved Price | ราคาหลังผ่านการอนุมัติ |
| ประเภทการคำนวน | Pricing Method | วิธีคิดราคา ค่าที่มี: `กรอกเอง` / `ราคาคงที่` / `ระยะทางคงที่` / `จากShipment` |
| ยอดต่างกัน | Difference Amount | ส่วนที่ราคาในระบบต่างจากราคาจริง → ต้องเบิกส่วนต่าง |
| ทำเบิกส่วนต่างScgวังน้อย | SCG Wang Noy Expense Claim | ตารางเบิกส่วนต่างรายงานสำหรับ SCG วังน้อย (136 คอลัมน์) |
| สรุปเบิกส่วนต่าง | Expense Difference Summary | ตารางสรุปการเบิกส่วนต่าง |
| สถานะ (ของการเบิก) | Claim Status | ค่าที่มี: `รอตรวจสอบ` / `ผ่านการตรวจสอบ` / `ไม่ผ่านการตรวจสอบ` |
| เบิกค่ายกขึ้นชั้น | Tiered Surcharge | การเบิกค่าเพิ่มตามระดับ (ท��มีบอทชื่อ "ทำเบิกค่ายกขึ้นชั้น") |
| สถานะการเข้ารับสินค้า | Return Receipt Status | สถานะรับสินค้าคืน ค่าที่มี: `(ได้เพิ่ม200) ไม่มีในจุดที่ส่งงานวันนี้`, `(ได้เพิ่ม200) ไม่มีสินค้าคืน หรือ ร้านปิด`, `(ได้เพิ่ม50%) ของค่าเที่ยว`, `(ไม่ได้เพิ่ม) มีในจุดที่ส่งงานวันนี้`, `ทำเบิกค่ายกขึ้นชั้น`, `เบิกค่าขนส่งตามระยะทาง` |
| รับงานคืนได้เงิน200 | Return-with-200-baht Job | งานที่รับคืนและได้เงิน 200 บาท |

## พนักงาน / รถ / อุปกรณ์

| ศัพท์ไทย | ศัพท์อังกฤษ | ความหมาย / ที่มา |
|---|---|---|
| ID_พนักงาน | Employee ID | รหัสพนักงาน (คอลัมน์ `ID_พนักงาน`) — ผูกกับ `USEREMAIL()` |
| Email พนักงาน | Employee Email | อีเมลผู้ใช้ที่ล็อกอิน (คอลัมน์ `Email พนักงาน`) |
| Email ผู้อนุมัติ | Approver Email | อีเมลผู้อนุมัติราคา |
| เลือกประเภทรถยนต์ | Vehicle Type | ประเภทรถ ค่าที่มี: `4 ล้อ` / `6 ล้อ` / `10 - 12 ล้อ` / `18 - 22 ล้อ/รถกึ่งพ่วง` / `รถพ่วง` |
| ข้อมูลการเข้าบำรุงรักษา | Maintenance Info | ข้อมูลการซ่อม/บำรุงรักษารถ |
| ซ่อมบำรุง | Maintenance | รายการซ่อมบำรุง (คอลัมน์ใน `ข้อมูลการเข้าบำรุงรักษา`) |
| ระบบบำรุงรักษา | Maintenance System | คอลัมน์อ้างอิงระบบบำรุงรักษาของรถ |
| ข้อมูลงานRT / ข้อมูลงานRW | RT / RW Job | งานประเภท RT และ RW (รถเส้นทาง / รถส่งของ) |

## เอกสาร / ประกาศ / ปัญหา

| ศัพท์ไทย | ศัพท์อังกฤษ | ความหมาย / ที่มา |
|---|---|---|
| ใบเสร็จ / ใบสลิป | Receipt / Slip | หลักฐานการรับเงิน (คอลัมน์ `รูปถ่ายใบเสร็จน้ำมัน_ใบเล็ก`) |
| Doc_Return | Returned Document | ตารางเอกสารคืนสินค้า (7 คอลัมน์) |
| Image_Doc_Return | Returned Document Image | รูปเอกสารคืนสินค้า |
| PDFพนักงาน | Employee PDF | PDF ที่สร้างให้พนักงาน (มี action export `PDFพนักงานcsv`) |
| ปริ๊นใบวางบิล | Print Bill | พิมพ์ใบวางบิล (ตาราง `ปริ๊นใบวางบิล`) |
| ใบประกาศ / หัวข้อประกาศ | Announcement / Title | ประกาศให้พนักงาน (ตาราง `Announcements`) หัวข้อประกาศมี 4 ประเภท: `กฎระเบียบและข้อบังคับ`, `แจ้งข้อมูลข่าวสาร`, `ความปลอดภัยและอุบัติเหตุ`, `สอบถามและรับฟังความคิดเห็น` |
| Acknowledge_Logs | Acknowledgement Log | บันทึกการรับทราบประกาศ (ตาราง `Acknowledge_Logs`) |
| เลือกเพื่อยืนยัน | Acknowledgement Choice | ผลการรับทราบ: รับทราบแล้ว / ติดขัดปัญหา |
| แจ้งปั ญหาระหว่างวัน | Mid-day Issue Report | ตารางแจ้งปัญหาระหว่างวัน (29 คอลัมน์, 11 ประเภทปัญหา) |
| ข้อมูลการแจ้งปั ญหา | Issue Detail | ประเภทปัญหา ค่าที่มี 11 รายการ เช่น `สินค้าชำรุด ตอนขึ้นงาน…`, `ถังน้ำมัน 200 ลิตรสินค้ามีน้ำหนักเกิน…`, `ร้านปิด`, `เบอร์โทรผิด…`, `ที่อยู่ผิด`, `ที่อยู่หน้าเอกสารกับที่อยู่หน้ากล่องไม่ตรงกัน…`, `สินค้าเสียหาย / ชำรุด`, `ลูกค้าไม่สะดวกรับสินค้า`, `จัดส่งสินค้าไม่ทัน`, `ไม่มีในจุดส่งงานวันนี้…`, `ลูกค้าไม่รับสาย ติดต่อ 3 ครั้งแล้ว`, `ติดต่อลูกค้าไม่ได้เข้าหน้างานไม่ถูก…`, `ปัญหาอื่นๆๆ` |
| ส่งรูปจุดที่ส่งงาน | Send Photo of Delivery Point | action ส่งรูปจุดส่งงาน |

## ระบบ / สิทธิ์ / มุมมอง

| ศัพท์ไทย | ศัพท์อังกฤษ | ความหมาย / ที่มา |
|---|---|---|
| ADMIN | Administrator | บทบาทผู้ดูแลระบบ (ค่า `ROLE`) — ใช้ในเงื่อนไข `USERROLE() = "ADMIN"` |
| USER | User | บทบาทผู้ใช้ทั่วไป (ค่า `ROLE`) |
| Security filter | Row Security Filter | `=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())` — พนักงานเห็นเฉพาะแถวของตัวเอง (คอมโมเกนตาราง `SCGนครหลวงJWDภูมิภาค`, `ข้อมูลการวางบิล`, `ข้อมูลการเข้าบำรุงรักษา`, `ตารางงานประจำวัน`, `แจ้งปั ญหาระหว่างวัน`) |
| ตารางงานประจำวัน | Daily Job Table | ตารางแกนกลาง — หนึ่งแถว = หนึ่งใบวางบิล/งาน |
| FILTER | Filter View | ตารางมุมมอง/ตัวกรองข้อมูล |
| หน้าหลัก | Home / Dashboard | ตารางหน้าแรกของแอป (4 คอลัมน์) |
| รอการอนุมัติ | Pending Approval | slice ที่กรองงานที่รออนุมัติ |

## คำย่อ / ชื่อเฉพาะ

| คำย่อ | ความหมาย / ที่มา |
|---|---|
| **SCG / SCGJWD / JWD** | ชื่อลูกค้า/ผู้ว่าจ้างงานโลจิสติกส์ (ปรากฏในชื่อตารางและกติกาความปลอดภัย) |
| **E-POD** | Electronic Proof of Delivery — คอลัมน์ `จำนวน_E-POD_ทั้งหมด` ในตารางสรุป |
| **RT** | ประเภทงาน RT (ตาราง `ข้อมูลงานRT`) |
| **RW** | ประเภทงาน RW (ตาราง `ข้อมูลงานRW`) |
| **SCG KM** | ระบบ KM (บอท `Process for AppSheet_KM`) |
| **MeSpace** | งานประเภทพิเศษ (บอท `Process for MeSpace`, enum `งานMeSpace+แพ็คสินค้า`) |
| **Plan Delivery** | วันที่วางแผนจัดส่ง (คอลัมน์ `Plan Delivery` ใน `ตารางงานประจำวัน`) |
| **LAT / LONG** | พิกัดละติจูด/ลองจิจูด คำนวณจาก `LatLong` ด้วย `LAT()` / `LONG()` |
| **Telegram** | ช่องทางแจ้งเตือน (บอท `Telegram_แจ้งปั ญหา`) |
| **GPS / HERE()** | ฟังก์ชันอ่านพิกัดตำแหน่งปัจจุบันของอุปกรณ์ |
